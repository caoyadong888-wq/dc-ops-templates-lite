# Racking checklist (lite)

The gates the full workbook scores when a host is actually racked. This lite page is the list, not the filled three-host batch.

- Rails match the chassis and the rack.
- Bonding jumper landed.
- Power A and power B both landed on labeled PDUs.
- Airflow direction matches the aisle.
- Blanking panels fill the gaps.
- Asset tag is on the ear and in the register.
- Firmware string recorded, management address in a private or documentation range.

中文：导轨、接地、双路电源、风向、盲板、资产标签、固件和管理地址。完整版带有已填写的三台服务器和会签。
