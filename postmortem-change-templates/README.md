# Postmortem and change templates (lite)

## English

## Purpose

Three short templates: a blameless postmortem, a CAB card, and a rollback sketch. The full pack adds the RFC, the docx copies, and the filled incident EX-2026-0218.

## Deliverables

- `deliverables/postmortem.md` — summary, impact, timeline, detection, root cause, action items, blameless statement.
- `deliverables/cab_checklist.md` — window, backout, monitoring, decision.
- `deliverables/rollback_plan.md` — trigger, owner, steps, verification, abort.

## Quick start

Copy a file and keep the `##` headings. Replace the guidance sentences with the incident you are writing up.
